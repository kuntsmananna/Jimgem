## Project

Jimgem ("gems cocktail os") — a mobile-first dashboard backed by the
owner's existing Google Sheets. Business logic/domain model is still
being defined; this repo currently only has the technical foundation.

## Stack

- Next.js 16 (App Router), React 19, TypeScript 5
- Tailwind CSS 4 — CSS-first config, no `tailwind.config.*`; customize via
  `@theme` blocks in `src/app/globals.css` if ever needed
- ESLint 9 (`eslint-config-next`, flat config)
- Package manager: npm (commit `package-lock.json`)

## File layout

- `src/app/**` — pages/layouts (App Router)
- `src/app/api/**` — route handlers for client-triggered interactivity
  (not for initial page data — see below)
- `src/lib/**` — server-only helpers, e.g. `src/lib/googleSheets.ts`
- Import alias `@/*` → `src/*`

## Styling conventions

Mobile-first Tailwind: write the unprefixed (mobile) layout first, then
layer `sm:`/`md:`/`lg:`/`xl:` for wider viewports. Never write a
desktop-first layout and override down with `max-w-`/`max-sm:` etc.

## Data-fetching conventions

- Server Components fetch Sheets data directly by calling
  `src/lib/googleSheets.ts` at render time — no client-side fetch needed
  for initial page data.
- `src/app/api/**` route handlers exist only for things a client needs to
  trigger after load (refresh buttons, future writes) or for external
  consumers.
- The Google service-account credential is only ever read inside
  `src/lib/googleSheets.ts`; nothing else should touch
  `process.env.GOOGLE_SERVICE_ACCOUNT_KEY_BASE64` directly, and it must
  never be exposed to a Client Component (no `NEXT_PUBLIC_` prefix).

## Google Sheets integration

- Auth: `googleapis`'s own `google.auth.GoogleAuth` (not the standalone
  `google-auth-library` package — that installs a second, type-incompatible
  copy since `googleapis` bundles its own), built from the service account
  JSON stored base64-encoded in `GOOGLE_SERVICE_ACCOUNT_KEY_BASE64`
  (`.env.local`, git-ignored). See `.env.local.example` for the expected
  shape.
- Client: `googleapis`'s `sheets_v4.Sheets`, built once and memoized in
  `src/lib/googleSheets.ts`.
- Scope in use: `spreadsheets.readonly`. Widen only when a write path is
  actually needed.
- Adding a new sheet-backed read: call the shared helper
  (`getSheetValues`) from `src/lib/googleSheets.ts` — don't construct a
  new `googleapis` client per call site.

## Environment variables

| Name | Purpose | Required |
|---|---|---|
| `GOOGLE_SERVICE_ACCOUNT_KEY_BASE64` | Base64-encoded service-account JSON key | yes |
| `GOOGLE_SHEETS_SPREADSHEET_ID` | Default spreadsheet ID for `/api/sheets` | no (or pass `?spreadsheetId=`) |
| `GOOGLE_SHEETS_DEFAULT_RANGE` | Default A1 range for `/api/sheets` | no (or pass `?range=`) |
